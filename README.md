# 회중 관리 화면 (GitHub Pages)

| 파일 | 대상 |
|---|---|
| `index.html` | 전도인 — 야외봉사 보고, 파이오니아 기록 |
| `elder.html` | 장로 — 출석부, 참석 현황, 봉사 현황, 연락망, 편성표, 회의록 |
| `secretary.html` | 서기·조정자 — 전도인·보고·집회 일정·설정·출력·점검 |
| `assets/config.js` | **서버 주소 (API_URL)** — 주소가 바뀌면 이 파일만 수정 |
| `assets/common.js` | 세 화면 공통 기능 |
